# @dsect/a2a-gateway

A2A 1.0 gateway + registry implementing the **DSECT A2A Profile v0.1**
(JSON-RPC binding, OIDC identity, five-tier trust), with an MCP facade so
MCP-speaking agents can delegate work over A2A.

**Start here: [docs/README.md](docs/README.md)** — what/why, quickstart,
layout, and links to the profile, trust model, MCP tool reference, and
connection guide.

Dev instance: Tritium, tailnet-only (`http://100.66.182.7:8340`). No
public listener in v0.1 — exposure is a separate, gated decision.
